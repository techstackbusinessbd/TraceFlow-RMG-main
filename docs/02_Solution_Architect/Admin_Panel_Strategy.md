# Admin Panel & HQ Dashboard Strategy
**Role:** Solution Architect / Frontend Developer
**Project:** RMG Traceability Software
**Status:** Approved for Implementation

---

## 1. Introduction
The Admin Panel (HQ Dashboard) is the central command center for the RMG Traceability Software. It is where Master Data is created, Roles are assigned, and factory-wide configurations are managed. This document outlines the technical strategy and core features of the Admin Panel.

---

## 2. Tech Stack Strategy (Custom React SPA)

### 2.1. Unified Codebase
- We will NOT use third-party backend admin generators (like Laravel Nova or Filament).
- **Reason:** Using a third-party generator creates a disconnected user experience and requires learning a new ecosystem.
- **Decision:** The Admin Panel will be built as a secure route (`/admin`) within our main **React (Vite) + TailwindCSS** Single Page Application (SPA).
- **Benefit:** 100% consistent UI/UX, single frontend repository to maintain, and seamless API integration via TanStack Query.

---

## 3. Core Features & Capabilities

### 3.1. User & Role Management (Spatie Integration)
- **User CRUD:** Create, edit, and disable user accounts.
- **Role Assignment:** Assign specific roles (e.g., `Super Admin`, `Factory Manager`, `QA Lead`, `Sewing Operator`) to users.
- **Permissions Matrix:** View and tweak granular permissions (e.g., "Can delete PO", "Can bypass QR check").

### 3.2. Master Data Control
This is the only place where Master Data is created. Factory floor tablets only *consume* this data.
- **Buyer Management:** Add/Edit Buyers (e.g., Zara, H&M).
- **Style & PO Management:** Input core PO details.
- **Factory Layout:** Define Sewing Lines (Line 01, Line 02) and Packing Stations.

### 3.3. Device & Hardware Management
- **Tablet Registration:** Register the MAC Address or Device ID of factory tablets.
- **Line Assignment:** Assign "Tablet 05" to "Sewing Line 02". If Tablet 05 is used on Line 01, the system flags a warning.

### 3.4. Audit & Activity Logs
- **Activity Log Viewer:** A dedicated screen to view logs generated by `spatie/laravel-activitylog`.
- **Purpose:** If a PO is accidentally deleted or a Shipment is forced open, the Admin Panel shows exactly *Who* did it, *When*, and their IP Address.

---

## 4. Access Control & Security
- **Strict Routing:** The `/admin` routes in React are protected by an `AdminRoute` wrapper component. It checks the user's role payload from the Sanctum API.
- **API Middleware:** Every backend endpoint starting with `/api/admin/*` must have the `middleware(['auth:sanctum', 'role:Super Admin|Factory Manager'])` applied.
