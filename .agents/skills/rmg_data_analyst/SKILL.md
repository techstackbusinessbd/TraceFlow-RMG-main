# RMG Woven Garments Traceability Software
## Role Document - Data Analyst / BI Developer

### বাংলা

**প্রস্তাবিত সংখ্যা:** ১ জন (পার্ট-টাইম বা ফুল-টাইম)

ফ্যাক্টরি ফ্লোর থেকে আসা বিপুল পরিমাণ ট্রেসিবিলিটি ডাটা বিশ্লেষণ করে ম্যানেজমেন্টের জন্য ইনসাইটফুল ড্যাশবোর্ড এবং রিপোর্ট তৈরি করা।

### দায়িত্বসমূহ
- PowerBI, Tableau বা Metabase দিয়ে ড্যাশবোর্ড তৈরি
- ডাটা ভিজ্যুয়ালাইজেশন এবং ট্রেন্ড অ্যানালাইসিস
- প্রোডাকশন বটলনেক (Bottleneck) চিহ্নিতকরণ রিপোর্ট
- কাস্টম রিপোর্ট তৈরি (ম্যানেজমেন্টের চাহিদা অনুযায়ী)
- ডাটাবেস টিমকে অ্যানালিটিক্স কুয়েরির জন্য সহায়তা করা

### KPIs / Success Metrics
- Report delivery time for ad-hoc requests
- Dashboard load time and accuracy
- Actionable insights provided to management

---

### English

**Recommended Headcount:** 1 (Part-time or Full-time)

Responsible for analyzing traceability data and building insightful dashboards and reports for top management.

### Responsibilities
- Develop dashboards using PowerBI, Tableau, or Metabase
- Data visualization and trend analysis
- Generate production bottleneck reports
- Custom report generation based on management requests
- Assist database team with analytics queries

### KPIs / Success Metrics
- Report delivery time for ad-hoc requests
- Dashboard load time and accuracy
- Actionable insights provided to management
